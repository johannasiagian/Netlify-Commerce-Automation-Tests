# Netlify Commerce App - Automated Testing with Selenium (Python)

This repository contains automated test scripts for the **Netlify Commerce App**, built using **Selenium** with **Python**.  
The tests validate essential e-commerce functionalities to ensure the application works reliably and provides a smooth user experience.  

## 📝 Features Tested
The automated tests cover the following user flows:
- **Login** – User authentication validation  
- **Add to Cart** – Adding products to the shopping cart  
- **Checkout** – Order placement flow  
- **Shipping Form** – Filling and submitting shipping details  

## 🛠️ Tools & Technologies
- [Selenium WebDriver](https://www.selenium.dev/)  
- Python (pytest/unittest)  
- Page Object Model (POM) for better structure and maintainability
